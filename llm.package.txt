Package: preact-missing-hooks
Version: 4.11.0

Description:
A lightweight, extendable collection of missing React-like hooks for Preact — plus fresh, powerful new ones designed specifically for modern Preact apps.

Exports:
- ClickOutsideEvent
- ClickOutsideTarget
- ConnectionType : Network connection type (e.g., wifi, cellular)
- DebouncedFunction
- DeviceBatteryInfo : Battery status from the Battery Status API when available
- DeviceBrowserInfo : Detected browser name and version
- DeviceData : Snapshot of device / browser data from native Navigator and related APIs
- DeviceOsInfo : Detected operating system name and version
- DeviceScreenInfo : Screen and display metrics from `screen` and `window`
- DeviceViewportInfo : Viewport size (`window.innerWidth` / `innerHeight`)
- EffectiveConnectionType : Effective connection type from Network Information API
- getDeviceData : Reads synchronous device / browser data from Navigator, Screen, and matchMedia.
- HoneypotAction
- HoneypotFieldProps
- HoneypotTriggerInfo
- HoneypotTriggerReason
- IDBController : Database controller built from an open IDBDatabase.
Exposes table(name) and transaction(...).
- IndexedDBConfig : Configuration passed to useIndexedDB.
- InjectableProps
- LLMConfig : Config for the useLLMMetadata hook. All fields optional except route.
- LLMPayload : Payload injected as JSON in the LLM script tag. Only includes defined, safe values.
- NetworkState
- OGType : Open Graph / content type for og:type.
- parseUserAgent : Parse browser and OS from a user-agent string (sync fallback).
- PreferredTheme
- RageClickPayload
- RBACAuthState : Get auth state (user + optional roles/capabilities). Used by custom source.
- RBACCapabilitiesOverride : Optional override: get capabilities directly (e.g. from API) instead of deriving from roles.
- RBACRoleCapabilities : Role name -> list of capability strings. Use '*' for full access.
- RBACRoleDefinition : Role definition: name + condition to grant this role based on user.
- RBACUser : Flexible user object; your app can use any shape.
- RBACUserSource : Pluggable source for current user (and optionally roles/capabilities).
- RunOptions
- ThreadedWorkerMode
- useClickOutside (Hook) : A Preact hook that calls `handler` when a pointer event happens outside the
given element (or elements). Useful for closing dropdowns, modals, and popovers.
- UseClickOutsideOptions
- useClipboard (Hook) : A Preact hook for reading and writing the clipboard. Uses the async
Clipboard API when available (requires secure context and user gesture).
- UseClipboardOptions
- UseClipboardReturn
- useDebounce (Hook) : A Preact hook that delays updating a value, or executing a function, until
`delay` milliseconds have passed without further changes/calls.
- useDeviceData (Hook) : Extracts device and browser data from native Navigator, Screen, window, and
matchMedia APIs. Updates on resize, orientation, online/offline, and
prefers-color-scheme / prefers-reduced-motion changes. Optionally polls the
Battery Status API when available.
- UseDeviceDataOptions
- useEventBus (Hook) : A Preact hook to publish and subscribe to custom events across components.
- useHoneypot (Hook) : Minimal honeypot protection for forms. Renders a hidden decoy field humans
ignore; bots often fill it. Optionally rejects submissions that happen too
fast after mount.
- UseHoneypotOptions
- UseHoneypotReturn
- useIdle (Hook) : A Preact hook that detects when the user has been inactive for `timeout`
milliseconds. Activity is inferred from window events (mouse, keyboard, touch, etc.).
- UseIdleOptions
- UseIdleReturn
- useIndexedDB (Hook) : Opens an IndexedDB database and returns a controller for tables and transactions.
Handles onupgradeneeded: creates object stores and indexes from config.
Connection is a singleton per (config.name, config.version).
- UseIndexedDBReturn
- useLLMMetadata (Hook) : Production-ready hook: injects an AI-readable metadata block into the document head
when the route changes. Framework-agnostic (React 18+ and Preact 10+ via aliasing).

- Rich structure: route, title, description, tags, outline (auto), canonicalUrl, language,
  ogType, ogImage, ogImageAlt, siteName, author, publishedTime, modifiedTime, robots, extra.
- Safe usage: never throws; invalid/missing config is normalized; DOM and JSON are guarded.
- Cacheable: if the generated payload is unchanged, the script is not replaced.
- SSR-safe: no-op when window/document is undefined.
- Cleans up on unmount (removes the script).
- useMediaQuery (Hook) : A Preact hook that tracks whether a CSS media query currently matches.
Updates reactively when the viewport or user preferences change.
- useMutationObserver (Hook) : A Preact hook to observe DOM mutations using MutationObserver.
- UseMutationObserverOptions
- useNetworkState (Hook) : A Preact hook that returns the current network state, including online/offline
status and (when supported) connection type, downlink, RTT, and save-data preference.
Updates reactively when the network state changes.
- usePoll (Hook) : Polls an async function at a fixed interval until it returns { done: true, data? }.
Useful for waiting on a backend job, readiness checks, or until a condition is met.
- UsePollOptions
- UsePollResult
- usePreferredTheme (Hook) : A Preact hook that returns the user's preferred color scheme based on the
`prefers-color-scheme` media query. Updates reactively when the user changes
their system or browser theme preference.
- usePrefetch (Hook) : A Preact hook that returns a stable prefetch function to preload URLs (documents or data)
so they are cached before the user navigates or needs them. Useful for link hover or
route preloading.
- UsePrefetchOptions
- UsePrefetchReturn
- useRageClick (Hook) : Detects "rage clicks" (repeated rapid clicks in the same area), e.g. when the UI
is unresponsive. Use the callback to report to Sentry or similar tools to surface
rage click issues and lower rage-click-related support.
- UseRageClickOptions
- UserAgentDataInfo : Parsed Client Hints from `navigator.userAgentData` when available
- useRBAC (Hook) : Frontend-only role-based access control hook. Define roles with conditions,
assign capabilities per role, and plug in user source (localStorage, sessionStorage, API, or custom).
Supports full flexibility: frontend-only with storage or pluggable API.
- UseRBACOptions
- UseRBACReturn
- useRefPrint (Hook) : A Preact hook that binds a ref to a printable section and provides a function
to print only that section using the native window.print() and
- UseRefPrintOptions
- UseRefPrintReturn
- useThreadedWorker (Hook) : Production-grade hook to run async work in a queue with optional priority
and either sequential or parallel execution.
- UseThreadedWorkerOptions
- UseThreadedWorkerReturn
- useTransition (Hook) : Mimics React's useTransition hook in Preact.
- useWasmCompute (Hook) : Runs WebAssembly computation in a Web Worker. Validates environment (browser, Worker, WebAssembly)
and returns a stable compute function plus result/loading/error/ready state.
- UseWasmComputeOptions
- UseWasmComputeReturn
- useWebRTCIP (Hook) : Attempts to detect client IP addresses using WebRTC ICE candidates and a STUN server.
Works frontend-only (no backend). Not guaranteed to return a public IP; use as a hint and
fall back to a public IP API (e.g. ipapi.co, ip-api.com) if you need reliability.
- UseWebRTCIPOptions
- UseWebRTCIPReturn
- useWorkerNotifications (Hook) : Listens to a Worker's messages and maintains state: running tasks, completed/failed counts,
event history, execution time per task, average duration, throughput per second, and queue size.
Worker should postMessage with: { type: 'task_start'|'task_end'|'task_fail'|'queue_size', taskId?, duration?, error?, size? }.
- UseWorkerNotificationsOptions
- UseWorkerNotificationsReturn
- useWrappedChildren (Hook) : A Preact hook to wrap children components and inject additional props into them.
- WorkerEventType : Supported worker event types for tracking. Worker should postMessage with these shapes.
- WorkerNotificationEvent
